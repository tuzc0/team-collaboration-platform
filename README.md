# Team Collaboration Platform

Plataforma de comunicación y gestión ligera de proyectos
con aplicaciones independientes para escritorio y móvil.

## Clientes

- Desktop: Java + JavaFX
- Mobile: Flutter + Dart

## Backend

- Auth Service: Rust + Axum
- Core Service: Elixir + Phoenix

## Persistencia

- PostgreSQL
- Cassandra / ScyllaDB
- Redis
- MinIO

## Infraestructura

- GNU/Linux
- Docker
- Docker Compose
